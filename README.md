# PinovX DevOps Associate – Practical Assessment

Welcome!

This repository is part of the PinovX DevOps Associate interview process.

## Objective

During the interview, you'll review a small set of infrastructure and deployment files that represent part of a staging environment.

The files may contain implementation issues, configuration problems, or opportunities for improvement.

Your task is to:

- Review each file carefully.
- Explain your thought process as you work.
- Make any changes you believe are necessary.
- Explain why you're making each change.
- Commit and push your changes to your branch.

The assessment focuses on your reasoning and approach rather than memorising syntax.

## Files Included

- `Dockerfile`
- `docker-compose.yml`
- `.github/workflows/deploy.yml`

## Before the Interview

Please ensure you have:

- Git installed
- A GitHub account
- A code editor of your choice (VS Code recommended)

You do **not** need to run the project locally unless specifically asked during the interview.

## During the Interview

1. Clone the repository.
2. Create a new branch using the format:

```bash
git checkout -b interview/<your-name>
```

Example:

```bash
git checkout -b interview/john-doe
```

3. Review the provided files.
4. Commit your changes with a meaningful commit message.
5. Push your branch to GitHub.

Example:

```bash
git add .
git commit -m "Improve Docker configuration and CI workflow"
git push origin interview/john-doe
```

## What We Evaluate

We're primarily interested in how you approach problems.

We'll be assessing:

- Troubleshooting and debugging
- CI/CD understanding
- Docker fundamentals
- Infrastructure reasoning
- Git workflow
- Communication and explanation of decisions

Perfection is **not** expected. If you're unsure about something, explain your thinking—we value your reasoning as much as the final solution.

Good luck, and we look forward to meeting you!
